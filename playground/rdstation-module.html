Comportamento do painel

  • Seção RD Station (BIT) aparece condicionalmente: só quando submit_actions contém bit_rdstation.
  • Controles são per-form — cada Form Widget tem os seus (permite reaproveitar a action em forms diferentes com tags / conversion_id distintos).
  • Defaults seguros: se Conversion Identifier ficar vazio, cai em DEFAULT_CONVERSION_ID = 'newsletter-footer-concertacao'.
  • Nenhum controle exige preenchimento técnico (token RD): a API Key vive em wp-config.php via constante RDSTATION_API_KEY — editor de conteúdo não vê secret.
  • Persistência: settings ficam em _elementor_data do template/página — copiar/exportar via Elementor Template preserva tudo (graças ao on_export() que limpa apenas chaves sensíveis e devolve o $element).

Características técnicas

Decisões de design que merecem destaque.

Graceful degradation

Qualquer falha (token ausente, timeout, 4xx/5xx, exception PHP) cai em log() + return. Form NUNCA chama add_error_message() — submit do usuário sempre completa.

Try/catch global (N1 v4)

Todo o corpo do run() envolto em try { ... } catch (\Throwable $e) — exception inesperada em PHP não escapa para o wrapper do Elementor Pro Form Action.

Log fora do webroot

/var/log/bit-rdstation/YYYY-MM-DD.log mode 750, owner www-data. Fisicamente inacessível via HTTP (validado empiricamente — nginx 404). LGPD-safe.

Secret leak guard (N3 v4)

Comentário inline na função log() proíbe explicitamente logar $url ou request headers — ambos contêm api_key na query string.

Timeout 8s

RD_TIMEOUT_SEC = 8 em wp_remote_post(). FPM worker bloqueado no máximo 8s — não satura pool em incidente de rede.

UF validada (lista BR)

Campo cf_uf só vai no payload se valor após sanitização bater com uma das 27 siglas BR. Senão, log warn e segue sem o campo.

Idempotência total

Bootstrap em wp-config.php com guard grep -q "RDSTATION_API_KEY"; mu-plugin com guard class_exists('\ElementorPro\Plugin'); re-rodar Task 3 não duplica nem 1 linha.

DEBUG opt-in

BIT_RDSTATION_DEBUG=true em wp-config.php habilita log nível info. Sem ele só vão a disco warn e error.

logrotate 90d (LGPD)

/etc/logrotate.d/bit-rdstation rotaciona daily / rotate 90 / compress. Janela suficiente para troubleshooting + PII não fica armazenada além do necessário (LGPD art. 16).

Constantes em wp-config.php

Bloco injetado de forma idempotente pela função setup_rdstation_constants() em bootstrap.sh. Em PROD, o sufixo _DEV/_HML/_PROD é resolvido pelo .env raiz via LINKED_ENV.

// ============================================================
//  RD Station — injetado pelo bootstrap.sh (idempotente)
//  Resolução do sufixo _DEV/_HML/_PROD é feita no docker-compose.yml
//  via ${RDSTATION_API_KEY_DEV} → variável de ambiente do container.
// ============================================================

// RDSTATION_API_KEY = token server-side aceito pela API
// /platform/conversions?api_key=X  (no painel RD chama "Identificador público")
if ( getenv( 'RDSTATION_API_KEY' ) ) {
    define( 'RDSTATION_API_KEY', getenv( 'RDSTATION_API_KEY' ) );
}

// BIT_RDSTATION_DEFAULT_TAGS = tags aplicadas globalmente além das do form
// (opcional, override pelo controle "Tags (CSV)" do painel Elementor)
if ( ! defined( 'BIT_RDSTATION_DEFAULT_TAGS' ) ) {
    define( 'BIT_RDSTATION_DEFAULT_TAGS', 'site-concertacao,form-rodape' );
}

// BIT_RDSTATION_DEBUG = se true, log nível 'info' também vai pra disco
// Sem ele, só 'warn' e 'error' são gravados — economia de I/O em produção.
if ( ! defined( 'BIT_RDSTATION_DEBUG' ) ) {
    define( 'BIT_RDSTATION_DEBUG', false );
}

Rollback em 1 comando

Desativação imediata sem revert de DB: basta remover o mu-plugin (Form Action vai sumir do painel; submits seguintes ignoram action).

# 1. Remover o mu-plugin (deploy + invalidar OPcache)
rm -f /var/www/html/wp-content/mu-plugins/bit-elementor-form-rdstation.php
rm -rf /var/www/html/wp-content/mu-plugins/bit-elementor-form-rdstation/
sudo systemctl reload php8.3-fpm

# 2. (Opcional) Remover constante do wp-config.php — não é mandatório
#    se mu-plugin não existe mais, a constante simplesmente fica órfã.

# 3. (Opcional) Walker idempotente que remove a action do _elementor_data
#    do template 72234 — espelho da Task 9 (Fix I8 v3).
sudo -u www-data wp --path=/var/www/html eval-file scripts/rdstation-unwire.php

Importante: rollback NÃO apaga /var/log/bit-rdstation/*.log — logs ficam para auditoria e são rotacionados normalmente pelo logrotate (90 dias).
